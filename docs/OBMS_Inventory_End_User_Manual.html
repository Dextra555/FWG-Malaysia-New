1. Getting Started

1.1 How to Log In to OBMS

  1. Open your web browser (Google Chrome or Microsoft Edge recommended).
  2. Enter the OBMS web address provided by your administrator.
  3. On the login page, enter your Username and Password.
  4. Click the Login button.
  5. If your credentials are correct, you will see the main dashboard.
If you see "Access Denied" or cannot log in, contact your system administrator to verify your user account and permissions.

1.2 How to Open the Inventory Module

After logging in, the left sidebar shows all available modules. Find the Inventory menu heading and click it to expand the sub-menu.

3. Opening Stock Entry

Opening Stock records the initial quantity of each item in each warehouse. Every entry creates an OPENING record in the Stock Ledger.

Rule: Only one opening stock entry per item per warehouse. Edit the existing entry to change it — do not create a duplicate.

3.1 How to Create

Path: Sidebar → Inventory → Opening Stock → + New

  1. Reference No is auto-generated (e.g., OS0001) — read-only.
  2. Select Opening Date (defaults to today).
  3. Select Warehouse (required).
  4. Select Item (required) — item details auto-display below.
  5. Unit Cost auto-fills from the item's Price — you can override.
  6. Enter Opening Qty (must be > 0).
  7. Total Value auto-calculates as Qty × Unit Cost.
  8. Click Save.

4.1 Purchase Requisition (PR)

Path: Inventory → Purchase Requisition → + New

Creating a PR

  1. PR Number is auto-generated (e.g., PR0012).
  2. Select PR Date and Required By Date.
  3. Enter Remarks if needed.
  4. Click Add Item to add line items.
  5. Select an Item — Buying Price auto-fills from the item's Price.
  6. Enter Required Qty (must be > 0).
  7. Click Add to save the line.
  8. Repeat for additional items.

4.3 Goods Receipt Note (GRN)

Path: Inventory → Goods Receipt → + New

Important: GRN is the only inventory transaction that creates a Finance record (CreditorInvoice). Deleting is blocked if a payment exists.
  1. GRN Number is auto-generated (e.g., GRN0008).
  2. Select an Approved PO — line items auto-load.
  3. Enter Supplier Invoice No and Delivery Note Ref.
  4. For each line, enter the Receiving Now quantity (cannot exceed Pending Qty).
  5. Click Save GRN.

5. Stock Management

5.1 Stock Issue

Path: Inventory → Stock Issue → + New

  1. Issue No is auto-generated (e.g., SI0015).
  2. Select Warehouse and Issue To Type (Staff/Guard/Other Guards/Branch/Other).
  3. Select the recipient from the dropdown (filtered by warehouse branch).
  4. For Guard/Staff: optionally check Salary Deduction (links to Payroll Uniform Loan).
  5. Add items: select Item, enter Issue Qty (≤ available stock), select Client (required).
  6. Click Save, then Print PDF.

5.2 Stock Issue Return

Path: Inventory → Issue Return → + New

  1. Select the Original Issue from the dropdown.
  2. Line items load with Issued Qty, Already Returned, and Returnable Qty.
  3. Enter Return Qty per line (cannot exceed Returnable Qty).
  4. Click Save.
Cannot be deleted or edited after saving. Verify quantities carefully.

5.3 Stock Transfer

Path: Inventory → Stock Transfer → + New

  1. Select Source Warehouse and Destination Warehouse (must be different).
  2. Add items: Item, Transfer Qty (≤ available stock in source).
  3. Click Save.

Creates paired ledger entries: TRANSFER_OUT (source) + TRANSFER_IN (destination).

5.4 Stock Adjustment

Path: Inventory → Stock Adjustment → + New

Key Rule: Stock Ledger entries are created ONLY on Approval, not on Save. Single item per document.
  1. Select Warehouse, Item, and Adjustment Type (PLUS or MINUS).
  2. Enter Adjustment Qty and Reason (required).
  3. Save Draft → Submit for Approval → Approver approves → Stock changes.

5.5 Stock Damage / Loss

Path: Inventory → Damage / Loss → + New

  1. Select Warehouse, Item, and Loss Type (Damage or Loss).
  2. Enter Quantity (≤ available stock) and Reason (required).
  3. Click Save — stock reduces immediately (DAMAGE_LOSS ledger entry).

5.6 Branch Stock Request (BSR)

Path: Inventory → Branch Stock Request → + New

  1. Select Requesting Branch and Source Warehouse.
  2. Add items: Item, Requested Qty, Client.
  3. Save Draft → Submit for Approval.
  4. When Approved: click Create Transfer — navigates to New Transfer with items pre-filled.

8. Approval and Notifications

Document TypeApproval Required?Default
Purchase RequisitionYesRequired
Purchase OrderYesRequired
Branch Stock RequestYesRequired
Stock AdjustmentConfigurableOptional (off)
Stock TransferConfigurableOptional (off)
Damage / LossConfigurableOptional (off)
Asset DisposalConfigurableOptional (off)

How to Submit

  1. Create the document and save as Draft.
  2. Click Submit for Approval.
  3. If routing is configured, the approver receives a real-time notification via SignalR.
  4. If no routing is configured, the document auto-approves immediately.

How to Approve/Reject

  1. Go to Administration → Pending Approvals.
  2. Open the submitted document.
  3. Click Approve (optionally enter remarks) or Reject (rejection reason is mandatory).
  4. The requester receives a notification of the decision.
SuperAdmin users can self-approve any document. The system uses your logged-in identity — you cannot approve on behalf of another user.

11. Glossary

TermDefinition
Approval RoutingConfiguration mapping a document type + requester to a specific approver
